# 📜 Oráculo de Scranton

Um gerador interativo de frases icônicas da série **The Office**, desenvolvido como projeto prático para treinar lógica de programação e manipulação de DOM. 

Acesse o projeto online: [Oráculo de Scranton](https://vissotoyohanna.github.io/oraculo-the-office/)

## 🚀 Funcionalidades

* **Sorteio Aleatório:** Gera uma nova sabedoria nível Dundie a cada clique.
* **Bilíngue:** Exibe as citações em Inglês (original) e Português, ajudando no treino do vocabulário.
* **Design de Carta:** Revela a foto do personagem como se fosse um card colecionável.
* **Easter Egg:** Uma animação especial (e dourada!) reservada para a clássica frase "That's what she said!".
* **Responsivo:** Layout totalmente adaptado para funcionar perfeitamente em computadores, tablets e celulares.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica.
* **CSS3:** Estilização, layout flexível, responsividade e animações de brilho (`@keyframes`).
* **JavaScript (Vanilla):** Lógica de sorteio, arrays de objetos e manipulação dinâmica de classes e elementos.
